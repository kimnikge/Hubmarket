# Структура кода HubMarket

## Основные директории

- `app/`: Содержит основные страницы приложения (главная, поиск, профиль и т.д.)
- `components/`: Содержит переиспользуемые компоненты
- `context/`: Содержит контекст приложения (AppContext)
- `pages/`: Содержит дополнительные страницы и API-роуты
- `styles/`: Содержит глобальные стили
- `lib/`: Содержит вспомогательные функции и утилиты
- `__tests__/`: Содержит тесты приложения

## Ключевые файлы

- `app/layout.tsx`: Корневой лейаут приложения
- `app/page.tsx`: Главная страница
- `app/search/page.tsx`: Страница поиска
- `pages/profile.tsx`: Страница профиля
- `context/AppContext.tsx`: Контекст приложения, управляющий состоянием пользователя
- `components/Layout.tsx`: Общий лейаут для страниц
- `components/BottomNavigation.tsx`: Компонент нижней навигации

## Стили

Приложение использует Tailwind CSS для стилизации. Основные настройки находятся в файле `tailwind.config.js`, а глобальные стили - в `app/globals.css`.

## Тестирование

Тесты расположены в директории `__tests__/`. Для запуска тестов используйте команду `npm test`.

## API роуты

API роуты расположены в директории `pages/api/`. Они обрабатывают серверные запросы, такие как аутентификация и управление данными.
